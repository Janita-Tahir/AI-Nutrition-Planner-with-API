NutriPlan represents an all-in-one full-stack web application designed for flawless deployment within a local XAMPP host environment. Specifically, its structure is built upon a native asynchronous JavaScript fetch API layer connecting the responsive frontend and customizable PHP/MySQL backend together. As far as the directory layout goes, it consists of modulized folders holding separate backend micro-APIs for any consumer interaction, an independent computational utility layer for specific calculations, and dedicated dashboards for administrators. Thanks to this file organization, both the database and third-party communication algorithms are entirely decoupled from publicly exposed user interfaces.

As for the core capabilities of the platform, they include data privacy and personalization through a combination of secure user registration procedures, based on native PHP hashing algorithms for password processing, and the operation of a custom computational system that calculates the user's BMI and assigns their weight class. This information serves as an input for an internal cURL API client, which sends requests to the Gemini model hosted at Google AI Studio, generating tailor-made 7-day meals plans in accordance with allergies, fitness goals, and medical records.
